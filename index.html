    Regras aplicadas

    Estas são todas as verificações que a ferramenta executa. Os problemas são divididos em quatro categorias: ausentes (célula sem valor), duplicados (linha repetida de forma exata), inconsistências (indícios de erro de formatação ou conteúdo, a revisar) e estrutura (linhas ou cabeçalho fora do formato esperado).

    Limitações

    • A ferramenta não detecta todos os erros possíveis. Valores errados mas bem formatados (um preço trocado, um nome com erro de digitação) passam despercebidos.
    • As inconsistências são indícios para revisão humana. Um valor sinalizado pode estar correto no seu contexto.
    • A duplicidade é avaliada na linha inteira. Repetição de apenas uma coluna-chave (por exemplo, o mesmo id com dados diferentes) não é sinalizada.
    • Datas com barra são lidas como DD/MM/AAAA. Arquivos em formato MM/DD/AAAA podem gerar sinalizações incorretas.
    • A validação de e-mail é simplificada e não verifica se o endereço existe.
    • O tipo de cada coluna é inferido por proporção de valores. Colunas com poucos valores preenchidos (menos de 3) não têm tipo nem padrão avaliados.
    • Aspas soltas no meio de um campo sem aspas são aceitas como texto comum, sem aviso.
    • O arquivo é lido inteiro na memória do navegador. Arquivos muito grandes podem deixar a análise lenta; o limite aceito é 25 MB.

    Data Quality Analyzer é um projeto de portfólio feito com HTML, CSS e JavaScript puros, sem backend e sem bibliotecas externas. Os dados demonstrativos são fictícios.
